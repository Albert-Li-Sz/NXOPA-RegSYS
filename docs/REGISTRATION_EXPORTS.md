# 报名信息导出与比赛账号

在活动的“报名管理”中选择“导出名单”，格式默认 Excel（.xlsx），也可选 CSV。导出覆盖当前筛选条件下的全部报名，每名有效成员一行，包含报名、队伍、成员、老师、实名单位、动态字段、审核、资格、考点、考场与座位。团队信息重复到每名成员行；财务列需要财务权限，金额只填在每份报名的第一名成员行。

Excel 使用真实 XLSX 工作簿，冻结表头并提供筛选。学号、手机号和账号使用文本单元格，保留前导零与长编号；CSV 使用 UTF-8 BOM，并转义公式字符。单次上限为 10000 名成员、500 列和 25 MiB，扫描资料最多 50 MiB。导出须有该活动的报名管理权限，响应禁止缓存，范围和数量写入审计日志。

## 比赛账号

活动设置中的“生成比赛账号”默认关闭。开启后填写账号前缀，“准考证显示账号密码”默认开启。取得参赛资格时自动生成账号；中途开启会为已有合格报名补齐。个人一人一组、团队全队共用一组，用户名形如 `nxcpc_0001`。比赛账号与本站登录账号分开。

密码随机生成并加密保存。重复生成、导出、重新取得资格、关闭再开启功能都复用原账号。首个账号生成后锁定前缀。关闭账号功能或报名失去资格后停止输出密码。普通报名详情与列表接口不返回密码。

导出时可勾选“包含比赛账号密码”，默认不勾选。准考证模板提供 `account.username`、`account.password` 条件变量。账号配置变化会使旧准考证失效，须重新生成、检查并发放。

## 实名单位

代表学校／单位由服务端引用本人或队长审核通过的实名资料，只读显示，不再填写简称、ICPC 编号或国家／地区代码。学校／单位是实名审核必填项。可以保存报名草稿，但提交与补正重提必须已通过实名审核且单位完整。允许团队成员来自不同单位；团队代表单位使用队长单位，提交时写入报名快照。
