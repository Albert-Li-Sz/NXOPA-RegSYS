# 账号邀请与 URL 授权

更新日期：2026-10-14，Asia/Shanghai。

公开邮箱注册继续开放，用户类型分为学生和教师。管理授权独立于用户类型，已有账号可在“管理员授权”中直接授权；也可使用需接收者确认的链接。链接邀请支持系统管理员、高级管理员、竞赛管理员和指导老师授权，采用“生成邀请 URL → 指定接收者登录并验证邮箱 → 明确确认 → 权限生效”。成员加入队伍、报名与老师关联继续使用原有确认链接。初始化管理员命令和开发演示数据用于建立初始环境，不受邀请流程替代。

## 管理员操作

在 **管理后台 → 用户与邀请** 点击“生成邀请链接”，选择账号邀请或角色、已有账号 / 指定邮箱，以及一至三十天的有效期，默认七天。竞赛管理员须选择具体竞赛；用户行上的“授权竞赛”“邀请系统管理员”“邀请指导老师”会预选接收者和身份。

链接生成后在对话框中复制，交给指定接收者。生成、复制和浏览邀请页均不授予权限；链接只在生成时展示。邀请列表记录接收者、身份、范围、到期时间及确认状态，可撤销等待确认的邀请。

已授予角色由用户行上的撤销操作即时取消，并使对应未确认角色邀请失效。撤销系统管理员时，其发出的未确认账号 / 角色邀请一并失效，即使重新获得系统管理员身份，原邀请也不会复活。指导老师身份撤销同时解除指导关系、移除报名访问与代办权限、使已取得的资格与准考证失效，报名需按竞赛规则补正。

## 接收者操作

打开 `/invite/:token` 后，未登录用户先进入登录页，登录成功返回邀请页。新用户可以在同一页面切换邮箱注册；邮箱验证邮件保留邀请返回地址，验证完成后仍需点击“确认接受”。邀请页展示接收者、邀请人、身份、权限范围和有效期。

仅指定账号 / 邮箱可确认，需已验证当前邮箱。账号邀请仅记录确认，不附加老师或管理员权限。竞赛管理员只获得链接对应竞赛的管理范围。已确认邀请重复提交安全；如果角色之后被撤销，旧链接会提示权限已撤销，并且不会重新授予权限。邀请到期限制确认时间，已经获得的角色不会因邀请 URL 到期自动撤销，但授权自身设置的 grantExpiresAt 会使权限到期。

## 实现与迁移

- `InvitationService` 负责账号及角色邀请，成员 / 老师关联由 `RegistrationService` 处理，复用同一确认路由。
- 数据库只保存 32 字节随机令牌的 SHA-256 摘要；列表和审计不返回原始令牌。HTTP 幂等结果按既有加密机制保存。
- 接收者绑定账号 UUID 和 / 或邮箱，确认时再次读取邮箱验证、发起人权限和竞赛；请求使用现有会话及 CSRF。
- PostgreSQL 事务锁序列化角色确认、角色撤销与老师关联，邀请码消费与角色写入原子提交。十次同时确认仅写一次角色和确认审计。
- 第六个迁移 `202610110006_authorization_invitations` 增加接收者、竞赛范围、确认时间与索引，既有账号、角色和成员 / 老师关系保留。
- 原 `POST /admin/roles` 正向授权返回邀请链接；负向撤销保持即时生效。教师注册具有指导老师身份，历史账号继续保留原指导授权；账号资料接口不允许本人变更指导授权。接口契约见 [API](API.md) 和 [OpenAPI](api/openapi.json)。
