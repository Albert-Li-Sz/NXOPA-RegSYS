# V0.3.1

本版加入 S3 文件存储、完整邮件通知、个人中心、学生视图和独立的管理员授权体系，同时保留旧部署、报名与附件数据。

- 修复 Linux 浏览器工单上传控件在手机宽度下的溢出问题，统一约束原生文件选择器。
- 安装支持用户输入 GitHub 加速前缀，并选择内置 MinIO、第三方 S3 或本地存储。Caddy 默认本机 8080，公网地址在系统管理员后台配置，仅用于生成链接。
- 附件、头像、准考证和模板预览统一使用存储接口；支持历史文件迁移、公开竞赛材料链接、私有队伍分发和队伍上传。加密备份包含 S3 对象，恢复后提供本地副本。
- 注册、邮箱验证与密码找回发送六位验证码；报名、开票、工单、实名审核和准考证发放提供邮件反馈。系统管理员可编辑各类邮件的完整 HTML / 纯文本格式，用户可查看投递状态并重发失败的业务邮件。
- 竞赛队伍公示支持队长标记、学校、排名、指导老师、审核状态和名单导出。学生视图按竞赛管理范围显示参与次数、非正式次数与活动详情。
- 用户分为学生、教师，增加入学年份 / 入职日期。个人中心提供资料、实名审核、报名、准考证、附件、管理信息与设置；注销保留历史，重新注册须经实名审核恢复查看。
- 管理员授权分为系统管理员、高级管理员、竞赛管理员，支持期限、权限项、撤回与卸任。高级管理员管理竞赛事务，核心配置仅系统管理员可修改；防止撤回最后一名永久系统管理员。

包含数据库迁移。已有实例先备份，再运行 `bash install.sh update`，保留原项目名、环境文件和加密密钥。旧环境未设置 STORAGE_MODE 时继续读取本地文件，可在后台配置 S3 后迁移。

[平台功能说明](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.3.1/docs/PLATFORM_GUIDE.md)包含具体页面、存储、邮件及授权操作。

验收覆盖独立生产 API、真实 SMTP / MinIO / LaTeX、权限和身份恢复，以及手机、平板、桌面页面；发布流程另行验证 amd64 / arm64 容器镜像安装、旧版升级和加密备份恢复。结果随发布附件提供。
