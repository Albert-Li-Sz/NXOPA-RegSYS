# v0.10.0

基于 v0.9.2 保留现有报名、排考、平台文件导出和准考证功能，统一比赛账号与密码。

- Hydro、DOMjudge 与准考证共用本人／团队队长学号及同一个系统随机密码，保留学号前导零。首次导出或生成准考证时按需生成并加密保存，重复及并发操作保持密码不变。
- DOMjudge 的队伍及账号 ID 使用报名 UUID，`accounts.team_id` 指向同一队伍；继续提供分组、学校、队伍、用户 JSON 和凭据表。
- 准考证默认显示比赛账号密码，模板支持 `account.username`、`account.password`。账号显示跟随平台文件导出开关，关闭后隐藏。学号或队长变化后保留密码、更新用户名，并使旧准考证失效。
- 保留 Hydro 的稳定报名 ID、队名、有效成员数组、教练、考场编号座位及布尔值正式／非正式标记；缺失或重复学号会明确指出报名并拒绝导出或生成。
- 镜像先发布固定版本标签，通过双架构安装和公开验证后再更新默认版本。
- 更新 Zod、邮件与上传组件等运行依赖至公告修复版本，并保留现有 MCP 与内部接口能力。

## 全新部署

本版本不提供旧业务数据或比赛凭据迁移。使用新的安装目录、Compose 项目名与数据卷安装，保留现有实例的独立备份。

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://raw.githubusercontent.com/Albert-Li-Sz/NXOPA-RegSYS/v0.10.0/install.sh -o install.sh
bash install.sh
```

V1.0.0 已弃用。v0.10.0 验收并公开发布后，下架 V1.0.0 的发布附件、版本标签及专属镜像；v0.9.2 保持可下载和拉取。
