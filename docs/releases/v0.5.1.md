# V0.5.1

本版增加空活动删除功能，统一按钮布局，并修复报名、附件、财务、审核、排考及草稿保护中的流程问题。

- 活动列表与详情支持删除无报名、无财务账户的活动。系统管理员和高级管理员可操作；草稿报名也会阻止删除，权限、版本及并发报名均由服务端检查。已有外接平台撤权待办仍可继续处理。
- 修复报名删除与上传、材料分发、工单创建的并发问题，防止删除后重新留下报名关联；报名表、工单和财务凭证按活动及用途校验附件，不能混用其他报名或独立工单的专属材料。
- 删除报名后，收款、退款、发票及附件继续独立保留；待发送和新产生的财务通知仍可投递，开票使用当前活动配置，费用与退款继续保留历史规则。
- 审核意见、发票申请、工单创建与回复、实名申请均增加离开和关闭草稿保护。保存失败保留填写内容，执行期间阻止重复提交；退出登录先确认未保存修改，取消时保留登录状态。
- 审核刷新失败后须重新加载再提交；连续审核的下一条加载失败时明确显示本条已保存。筛选变化立即废弃旧批量操作范围，等待或失败期间禁用批量操作，并保留有效的跨页勾选。
- 排考预览期间锁定范围，预览或提交失败后要求重新核对；没有实际变化的考场保存或相同座位分配不再使准考证失效。
- 修复键盘提交绕过开票确认、专用发票误选个人抬头、工单附件尚未上传完成就提交、重复成员编号覆盖队长，以及撤销工单权限后仍可读取缓存响应等问题。
- 统一工具栏、文件导入、表格操作和弹窗按钮的对齐与间距；窄屏弹窗按可用宽度排列。已核对桌面、831 像素窄屏及 390 像素手机界面。

本地验收通过十九组完整回归、七十五个浏览器场景和十三项单元测试，以及类型检查、格式检查和生产构建。发布流程重新验证当前标签，并执行双架构镜像实际安装、升级、交互维护、代理及加密备份恢复；报告、镜像摘要和 SHA256 校验文件随 Release 提供。

从 v0.5.0 升级没有新增数据库迁移。已有实例使用 `bash install.sh update`，更新前自动生成加密备份，请保留数据库、附件及原加密密钥。从 v0.4.0 或更早版本升级仍会执行 v0.5.0 的财务迁移及历史取消报名永久清理；此类升级回退需要恢复升级前数据库和文件备份。

镜像：`ghcr.io/albert-li-sz/nxopa-regsys-{api,worker,web,latex,minio}:v0.5.1`，支持 `linux/amd64`、`linux/arm64`，同时更新 `v0.5` 与 `latest`。

本版不自动升级既有服务器；真实远端 Hydro／DOMjudge 操作及飞书授权页面未重跑，已验证本地权限、任务边界及飞书协议流程。

操作说明见[平台指南](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.5.1/docs/PLATFORM_GUIDE.md)，详细验证见[验收报告](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.5.1/docs/ACCEPTANCE.md)，升级步骤见[部署说明](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.5.1/docs/DEPLOYMENT.md)。
