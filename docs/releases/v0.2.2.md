# V0.2.2 · HTTP 登录、账号状态与窄屏布局修复

修复普通 HTTP 部署下登录和表单提交无响应的问题，并修复账号状态及手机页面布局。沿用 V0.2.0 的单入口安装、GitHub 登录、用户标签、资料完善门槛和按首次提交时间编号。

## 修复内容

- 普通 HTTP 页面不提供 `crypto.randomUUID()`，之前生成请求标识时抛错，登录和保存表单未发出请求。现在使用浏览器随机数生成兼容的 UUID，HTTP / HTTPS 均可提交，CSRF 校验保持有效。
- 已登录用户重置密码后，后端会撤销会话；前端现在同步登录状态并返回登录页，不再显示失效的账号中心。
- 撤销当前登录会话后立即返回登录页；撤销其他会话保留当前登录。
- GitHub 设置页的长回调地址可以换行，不再撑宽手机页面。
- 导航栏限制姓名显示宽度，长姓名省略显示并保留完整提示，避免页面横向溢出。

- 约束报名管理页座位 CSV 上传控件的宽度，适配 Linux 浏览器原生文件选择器，并清理多余显示符号。

## 验证

新增回归覆盖 22 个页面 / 页签在 360、768、1440px 下的 66 组布局检查，以及长姓名、真实非安全 HTTP 登录与资料保存、密码重置、当前会话撤销。总计 70 项界面检查通过，无页面脚本错误。类型检查、6 项单元测试、构建和格式检查通过。

发布流程还在原生 amd64 / arm64 上核验镜像安装、交互更新与卸载、HTTPS 双层代理、历史版本数据升级和加密备份恢复，成功后生成安装包及验收报告。

## 更新

在已有安装根目录运行：

```bash
bash install.sh update
```

新安装可下载本 Release 的 `nxopa-regsys-v0.2.2-install.tar.gz`，核对 `SHA256SUMS` 后解压并运行 `bash install.sh`。默认内部 Caddy 监听 `127.0.0.1:8080`，由自有反向代理配置公网访问。

本补丁不新增数据库迁移；更新脚本仍先创建加密备份。配置教程和 Hydro 0.2.0 插件继续随发布提供。
