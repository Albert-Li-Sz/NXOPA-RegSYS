# v0.9.1

Hydro 导入包改为使用报名学号登录，并新增独立考场编号。JSON、凭据表、管理界面和配置教程采用相同映射。本版包含数据库迁移；升级前备份数据库、附件和原 ENCRYPTION_KEY。

- Hydro `teams.json` 保持数组格式，`id` 固定使用报名 UUID，`name` 使用个人本人／团队队长报名资料中的学号；学号按字符串保留前导零，并按 Hydro 的 SASLprep 规则规范化。缺失、格式不符或规范化后忽略大小写重名时整包拒绝，并指出对应报名。
- `displayName` 保留填写的队名，个人赛使用姓名；密码沿用独立且加密保存的比赛密码，重复导出保持不变。有效队员只写入 `members`，队长在前，支持四名及更多成员，不同时输出 `member1` 至 `member4`。教练、代表学校和布尔值 `rank` 继续按报名导出。
- 考场新增可选编号，支持字母、数字、下划线和连字符，最长 20 字符；去除首尾空格后统一大写，同一活动内唯一。编号可在“考场与座位”新增、查看、修改和清空；接口省略编号时保留原值。
- Hydro `seat` 改为考场编号加至少两位座位序号，例如 `A01`、`A100`；未排座或编号为空时写入空字符串，不再添加活动前缀或回退到人工队伍编号／报名编号。允许多个空座位，非空座位冲突或同一队伍存在多个成员座位时拒绝导出。
- `credentials.csv` 与 JSON 使用同一学号、比赛密码和座位。DOMjudge 的账号、活动前缀、分组及文件关联规则保持原有行为。
- 同步更新 OpenAPI、导出说明、配置教程网页、PDF 及操作截图；增加字段映射、Unicode 重名、座位边界、旧考场迁移、页面下载和真实 Hydro 导入／登录的回归验证。

- 将 DOMPurify 升级至 3.4.17，并将 MCP 限流依赖链中的 ip-address 固定到 10.7.4，清除依赖审计发现的四条运行时公告。发布和发布前预检流程增加运行时依赖审计门禁。修复版本依据 [DOMPurify 公告](https://github.com/advisories/GHSA-cg2g-xh64-v4q7) 和 [ip-address 公告](https://github.com/advisories/GHSA-rxp7-6hxx-x8q5)。

## 升级与核对

在原安装目录执行：

```bash
installer_tmp="$(mktemp)"
curl --proto '=https' --proto-redir '=https' -fsSL https://raw.githubusercontent.com/Albert-Li-Sz/NXOPA-RegSYS/v0.9.1/install.sh -o "$installer_tmp"
NXOPA_ROOT="$PWD" NXOPA_UPDATE_TAG=v0.9.1 bash "$installer_tmp" update --yes
rm -f "$installer_tmp"
```

本版的 Hydro 导出按每场比赛清空 Hydro 后导入的使用方式设计，不兼容旧导入账号或跨活动复用。请在新比赛环境导入，避免在进行中的比赛直接切换账号体系。本站只生成文件，清理和导入由主办方在 Hydro 执行。

旧考场迁移后编号为 `null`，原考场名称、容量及座位保留，不根据名称自动推测编号。需要 `A01` 等座位时先补填考场编号；留空仍可导出账号。修改编号会沿用排考版本校验，并使受影响准考证失效，须重新生成。

导入后使用学号和包内比赛密码实际登录，核对队名、成员、座位、正式／非正式性质及比赛访问。Hydro 重复导入会用文件中的 `password` 重设远端密码；使用 IP 登录前先补齐非空座位。

数据库只使用 `prisma migrate deploy`，禁止以 `db push` 替代迁移。回退须恢复兼容备份。发布报告、双架构镜像清单与附件校验和随版本提供；操作步骤见 [在线配置教程](https://albert-li-sz.github.io/NXOPA-RegSYS/) 和 [平台导入说明](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.9.1/docs/INTEGRATIONS.md)。
