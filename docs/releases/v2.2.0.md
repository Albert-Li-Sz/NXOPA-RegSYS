# v2.2.0

## 更新

- Hydro 新增报名资料字段关联：displayName、school、members、coach、seat 可关联姓名、队名、基础资料及当前／历史自定义表单字段。关联仅本次导出生效，缺值自动回退系统默认来源；成员资料逐人取值并逐人回退姓名，包内说明列出回退数量。
- id、name、password、rank 的来源保持固定。Hydro、DOMjudge 和准考证继续共用本人／队长学号及稳定比赛密码；默认一键导出使用原有系统规则，不应用本次关联。JSON 与凭据 CSV 同步使用关联结果，省略密码时整个 ZIP 不含比赛密码。
- 竞赛卡片的查看竞赛箭头统一为 `>>`，查看竞赛与队伍公示改为等宽并排按钮，修正手机布局和按钮偏移。
- 管理列表的删除、编辑配置、报名管理保持同一行。删除限制原因改为静态圆点提示，支持鼠标悬停、键盘聚焦和点击查看。
- 更新导出 API、教程和实际界面截图，补充字段来源、恢复默认、缺值回退、权限、真实平台重导与响应式布局回归。

## 安装与保留数据升级

安装包和五类业务镜像使用固定版本 v2.2.0，提供 linux/amd64、linux/arm64。核对 SHA256SUMS 后解压安装包运行 `bash install.sh`。

v2.1.0、v2.0.0 和 v0.10.2 在原安装目录执行：

```bash
NXOPA_UPDATE_TAG=v2.2.0 bash install.sh update --yes
```

升级先建立加密备份，保留原数据卷、加密密钥、账号、报名、财务、文件及比赛凭据。本次字段关联是请求参数，不新增持久化配置或业务数据迁移；沿用既有幂等迁移。降级前恢复升级前的数据库和附件备份。

v0.9.x 和已弃用的 v1.0.0 继续使用独立安装目录和数据卷全新部署。

## 导入注意

省略 password 不重置已有 Hydro 账号密码，新账号由 Hydro 自行生成密码，可能与准考证不同；省略 members 可能清空已有远端成员。自定义学校与座位按实际来源校验，非空座位仍须唯一且不能包含逗号或换行。默认完整导出维持既有共享凭据规则。

## 发布验收

发布门槛包括完整回归、Browser 交互、真实 Hydro／DOMjudge 导入及登录、双架构全新安装与重启、加密备份恢复，以及 v2.1.0、v2.0.0、v0.10.2 的保留数据升级。通过验收后更新 Latest，安装与回归报告随 Release 提供。
