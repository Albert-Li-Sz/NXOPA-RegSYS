# v2.2.3

## 修复

- 报名审核、缴费核账、退款和开票通知改用中文结果，邮件“状态”栏不再显示 `APPROVED`、`ISSUED` 等英文状态码。
- 接口参数校验失败时返回中文说明，例如 `contestId：无效UUID`；表单校验同步使用中文提示。
- 每名参赛者在同一活动中只能保留一份报名，报名创建者和已加入的队员均适用。重复创建返回“您已报名此活动”，活动页改为显示“查看我的报名”。
- 准考证和平台导出的下载文件名按 RFC 5987 编码；批量生成准考证启用座位自动递增时，跳过的报名不再占用座位号。

## 界面

- 断网或请求超时时显示中文提示，不再无响应；附件预览的网络错误同样改为中文。
- 按站点主色生成完整色阶，按钮悬停、禁用、plain 样式和焦点框跟随主题色；原先写死的品牌色改为跟随主色。
- 后台任务、缴费凭证、退款和发票使用各自的状态文字，例如“等待执行”“待核账”“已批准”“已退款”“待开票”。
- 活动详情页：免费活动不显示财务页，移除对管理员无效的标签筛选，页面称呼统一为“活动”。
- 登录页提高正文对比度，平板宽度改为限宽单栏布局。

## 安装与保留数据升级

安装包和五类业务镜像使用固定版本 v2.2.3，支持 linux/amd64 和 linux/arm64。核对同一 Release 的 SHA256SUMS 后解压安装包，运行 `bash install.sh`。

v2.2.2、v2.2.1、v2.1.0、v2.0.0 和 v0.10.2 可在原安装目录执行：

```bash
NXOPA_UPDATE_TAG=v2.2.3 bash install.sh update --yes
```

更新先建立加密备份，保留原数据卷、加密密钥、账号、报名、财务、附件及共享比赛凭据，再启动新版服务。本版不含数据库迁移；从 v2.2.1 及更早版本升级时仍会执行此前版本的迁移。

已存在的同一活动多份报名会保留，新规则只阻止再次创建。降级须恢复升级前的数据库和文件备份。v0.9.x 和已弃用的 v1.0.0 继续使用独立安装目录和数据卷全新部署。

## 验收

新增重复报名和中文审核通知两项缺陷回归，更新相应单元测试与浏览器回归。发布流程执行完整业务及浏览器回归、真实 Hydro/DOMjudge 导入与登录，以及双架构全新安装、加密备份恢复和上述五个版本的保留数据升级。验收报告随 Release 附件提供。
