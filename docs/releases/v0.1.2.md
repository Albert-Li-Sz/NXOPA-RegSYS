# V0.1.2 · 安全与业务流程修复

修复邮箱修改后旧链接仍能验证或重置账号的问题，并补齐取消报名、非正式参赛付款和团队工单的权限与状态处理。

## 修复

- 修改邮箱时，原邮箱的验证和密码重置链接立即失效。链接签发、使用和邮箱修改采用同一用户锁，避免并发操作留下有效的旧链接。
- 升级迁移使旧版本尚未使用的验证及重置链接失效，保护升级前已修改邮箱的账号。已有登录会话和报名资料保留；需要验证邮箱或重置密码的用户重新申请链接。
- 取消免费报名及申请取消已付款报名时，资格变化会发送 Outbox 事件，通知签名 Webhook 并撤销本地评测平台映射资格。
- 采用“先审核再付款”时，非正式参赛必须先通过管理员审核，再上传付款凭证，即使比赛对正式参赛启用了自动审核。
- 团队成员可在工单列表找到有权查看的团队工单；未关联的私人工单仍受保护，成员移除后访问随之撤销。
- 浏览器测试自行创建个人报名数据，并将首页状态检查限定到演示竞赛，减少测试对历史数据的依赖。

## 安装与升级

四个业务镜像均使用 `v0.1.2` 标签，支持 `linux/amd64` 与 `linux/arm64`：

- `ghcr.io/albert-li-sz/nxopa-regsys-api:v0.1.2`
- `ghcr.io/albert-li-sz/nxopa-regsys-worker:v0.1.2`
- `ghcr.io/albert-li-sz/nxopa-regsys-web:v0.1.2`
- `ghcr.io/albert-li-sz/nxopa-regsys-latex:v0.1.2`

新安装下载 `nxopa-regsys-v0.1.2-install.tar.gz`，解压后进入 `install` 目录，依次执行 `bash install.sh init`、配置域名与端口、`bash install.sh up` 和 `bash install.sh admin`。

已有镜像部署保留原 `.env`、项目名、数据库密码及加密密钥，将 `IMAGE_TAG` 改为 `v0.1.2`，执行 `bash install.sh update`。该命令先加密备份，再更新容器并运行迁移。请保留生成的备份；无需重新创建管理员。源码部署更新至本标签后执行相同命令。

附件包括安装包、镜像摘要 `images.json`、两种架构的实际安装与 v0.1.1 升级验收记录、配置教程、Hydro 插件及 `SHA256SUMS`。使用 `sha256sum -c SHA256SUMS` 校验附件。

## 验证

发布流水线运行 5 组 BUG 回归，并分别在 amd64 / arm64 原生环境验证空库安装、浏览器登录、中文准考证、容器重启、加密备份恢复和 v0.1.1 升级。升级检查覆盖报名、附件、准考证及会话保留，以及遗留邮件链接失效和新链接可用。

本机业务、权限、邮件与真实 Hydro / DOMjudge 联动验证结果见 [本版本验收记录](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.1.2/docs/releases/v0.1.2-verification.md)。公网域名证书和真实 SMTP 送达仍需在具体部署环境验证。取消报名会撤销本地账号映射资格；已有远端评测账号的禁用仍按管理员流程处理。
