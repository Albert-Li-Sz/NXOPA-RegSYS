# v0.10.1

本版本统一按钮与操作区布局，修复失效页面数据、禁用模块入口和模板预览交互。比赛账号、平台导出和准考证继续沿用 v0.10.0 的共享凭据规则。

- 同一操作区的按钮保持一致宽度和间距，表格行内操作使用紧凑布局；登录、OAuth、会话恢复和 PDF 预览控件统一尺寸。移动端操作区自动换行。
- 内外部链接使用单个交互元素，支持键盘焦点；按钮仅对颜色、边框和阴影进行短暂过渡，并遵循减少动态效果设置。
- 活动编辑页自动修正已关闭模块或无效标签页的旧链接，避免请求不可用的考场与准考证模块。
- 公开名单刷新时清除旧数据，加载、关闭和异常状态隐藏导出入口；恢复后可重试。
- 调整报名总览筛选与操作排列；不可删除的活动显示明确原因，禁用按钮不再响应操作。
- 发布流程核对固定版本、源码提交、附件校验和及双架构镜像后再更新 Latest，阻止旧版本误覆盖当前版本。

## 安装与升级

新部署下载本 Release 的安装包，对照 `SHA256SUMS` 校验后解压并运行 `bash install.sh`。镜像均使用完整固定版本 `v0.10.1`，支持 linux/amd64 与 linux/arm64。

从 v0.10.0 升级时，在原安装根目录执行：

```bash
NXOPA_UPDATE_TAG=v0.10.1 bash install.sh update --yes
```

更新会先建立加密备份。保留原配置、数据卷和 `ENCRYPTION_KEY`，使会话、报名、附件及共享比赛密码持续可用。v0.9.x／v1.0.0 不在本版本的数据迁移范围内，请使用独立安装目录和数据卷部署。原 v0.9.2 版本继续保留。
