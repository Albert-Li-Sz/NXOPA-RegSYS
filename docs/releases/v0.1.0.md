# V0.1 · 南晓开放原子社在线报名系统

首个公开版本，源码标签为 `v0.1.0`。官网采用蓝白界面和独立介绍首页，进入报名系统后使用邮箱 / 账号密码登录。

## 功能

- 个人与团队报名、竞赛字段配置、指导老师确认、审核与资料补正；正式 / 非正式参赛由管理员审核。
- 系统管理员、竞赛管理员、参赛者与指导老师；账号邀请和权限授权通过 URL 确认。
- 线下收款凭证、部分到账核账、退款申请与记录、普票 / 专票申请和发票上传。
- 工单与邮件通知、全局及竞赛 LaTeX 准考证模板；个人一张、团队共用一张。
- Hydro 5.0.7 插件与 DOMjudge 9.0.1 注册联动，包含学校映射、队伍、比赛账号和非正式参赛。
- 版本化联合注册 API、签名 Webhook、竞赛范围 Token 与只读 MCP。
- 系统管理中心配置公网地址、SMTP 和评测平台；日志分页、Markdown 竞赛介绍及手机布局。

## Docker 镜像

四个业务镜像支持 `linux/amd64` 与 `linux/arm64`：

| 服务   | 版本镜像                                          |
| ------ | ------------------------------------------------- |
| API    | `ghcr.io/albert-li-sz/nxopa-regsys-api:v0.1.0`    |
| Worker | `ghcr.io/albert-li-sz/nxopa-regsys-worker:v0.1.0` |
| 前端   | `ghcr.io/albert-li-sz/nxopa-regsys-web:v0.1.0`    |
| LaTeX  | `ghcr.io/albert-li-sz/nxopa-regsys-latex:v0.1.0`  |

同时提供 `v0.1` 和 `latest` 标签。正式部署固定 `v0.1.0` 或使用附件 `images.json` 的内容摘要。PostgreSQL、Redis 和 Caddy 分别使用官方镜像，只有 Caddy 暴露端口。

## 安装

下载本页的 `nxopa-regsys-v0.1.0-install.tar.gz`，无需 Node.js 或业务源码：

```bash
tar -xzf nxopa-regsys-v0.1.0-install.tar.gz
cd nxopa-regsys-v0.1.0/install
bash install.sh init
# 公网部署先按 README 修改 .env 的域名、HTTPS 与端口
bash install.sh up
bash install.sh admin
```

安装包默认拉取镜像；保留完整仓库时也可以使用 `INSTALL_MODE=source` 从源码构建。已有部署保持原项目名、数据库密码与加密密钥，先备份再更新，不重新初始化管理员。

附件包含安装包、教程 PDF、教程源码与截图 ZIP、Hydro 插件、镜像摘要和 `SHA256SUMS`。使用 `sha256sum -c SHA256SUMS` 校验下载。详细配置与插件说明见 [在线教程](https://albert-li-sz.github.io/NXOPA-RegSYS/)。

## 验证范围与限制

发布流程对两个架构的实际镜像运行独立 PostgreSQL / Redis 安装验收，覆盖管理员登录、浏览器回跳、报名、私有附件、中文准考证、重启、加密备份恢复及公网地址恢复。平台联动和业务增强的本机实际验收记录见 [增强验收](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.1.0/docs/ENHANCEMENT_ACCEPTANCE.md)，源码安装与已有实例升级记录见 [安装验收](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.1.0/install/ACCEPTANCE.md)。

首版使用线下财务；不包含在线支付、电子发票服务、OAuth / OIDC、多租户或机器人写操作。实际域名的证书签发与公网邮件送达需要部署后使用自己的 DNS 和 SMTP 验证。
