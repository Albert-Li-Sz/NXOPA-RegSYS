# V0.4.0

本版完善邮箱注册验证和账号管理，重组个人与管理员导航，新增飞书登录、活动统计大屏和按顺序切换的备用 SMTP，并修复邮件模板编辑及预览。

- 注册前必须完成邮箱验证码验证，验证码限时、限次且只能使用一次；请先在管理中心配置可用 SMTP。
- 系统管理员可在学生、教师详情中编辑资料、封禁、解封和删除账号；删除后保留历史报名与附件，并防止删除最后一个系统管理员。
- 顶部增加活动总览，支持总体和单个活动统计、全屏及自动刷新，统一使用系统浅色卡片风格。
- “活动及竞赛中心”、我的报名、我的准考证、我的附件作为同级入口；点击 Logo 返回首页，个人菜单进入个人信息。管理员功能分别归入竞赛中心、外接平台中心、用户中心、日志与任务中心和审核中心。
- 新增飞书登录和主动绑定、解绑。首次注册仍须本站邮箱验证，飞书联系邮箱不会直接用于合并已有账号；管理员需配置 App ID、App Secret 和回调地址。
- 邮件服务支持主 SMTP 和最多十个备用服务器，管理员可调整顺序、检测连接和测试实际投递；发送失败后依次尝试，成功即停止。
- 修复邮件模板切换时丢失编辑草稿的问题，保存、预览和测试投递使用一致的渲染逻辑。新工单等通知采用对应业务正文，仅验证类默认模板包含验证码，已自定义的模板保留。
- 附件增加 PDF 页面内阅读器，支持中文页面、翻页和缩放，并沿用文件权限；修复中文上传文件名乱码。
- 登录会话固定每页二十条，支持分页及撤销；性别仅允许男、女，下拉框支持输入筛选，按钮与导航对齐统一。

本版新增邮箱注册验证记录及账号封禁字段。已有实例请先备份，再运行 `bash install.sh update`；数据库迁移会自动执行，保留现有账号、报名、文件和邮件配置。镜像支持 linux/amd64 与 linux/arm64，正式发布前完成安装、旧版升级、双层代理和加密备份恢复验收，结果随 Release 附件提供。

新导航、飞书及邮件配置详见随发布包提供的 [平台指南](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.4.0/docs/PLATFORM_GUIDE.md)。
