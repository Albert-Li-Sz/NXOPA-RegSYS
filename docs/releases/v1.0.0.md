# v1.0.0

报名导出、独立比赛账号与准考证批量发放正式版。

- 移除 Hydro／DOMjudge 导出、外接平台中心、平台字段模板与绑定、撤权待办，以及 API Token、Webhook、第三方查询接口和 MCP 适配器。保留网站内部 API、GitHub 和飞书登录。
- 报名支持 Excel（默认）和 CSV，导出当前筛选条件下的全部报名，每名选手一行。保留动态字段、实名单位、指导老师、考点与座位，财务列按权限输出；账号密码需单独勾选。
- 活动可选择生成独立比赛账号，个人一组、团队共享一组。取得资格后自动生成，中途开启自动补齐；前缀在首次生成后永久锁定，删除全部报名也不会解锁，重复操作保留密码，默认显示在准考证上。
- 代表单位只读引用本人或队长审核通过的实名单位。实名单位为必填文本，提交和补正重提校验已审核身份；允许跨单位组队。
- 准考证支持跨页勾选和全部筛选，先生成 PDF、管理员检查，再批量发放。提供任务进度、逐条结果和失败重试；重复发放不重复通知，大 ZIP 自动分包。
- 修复竞赛卡片按钮齐边、列表操作同行、删除原因悬停与键盘聚焦、详情按钮等宽及手机布局问题。
- 更新内部任务服务、存储备份恢复、OpenAPI、生成客户端、教程和验收流程，并修复运行依赖公告。

## 部署

v1.0.0 面向全新部署，不提供旧平台账号、已移除接口或历史报名数据的兼容适配。已有 v0.x 实例先保留数据库、附件和原加密密钥的独立备份，再使用新的安装目录、Compose 项目名与数据卷安装；不要将 v0.x 的备份直接恢复到新的 v1.0 实例。

```bash
curl --proto '=https' --proto-redir '=https' -fsSL https://raw.githubusercontent.com/Albert-Li-Sz/NXOPA-RegSYS/v1.0.0/install.sh -o install.sh
bash install.sh
```

安装包、五类服务的 amd64／arm64 镜像、配置教程 PDF 和源码包随 Release 提供。使用方法见 [报名导出与比赛账号](../REGISTRATION_EXPORTS.md)、[准考证说明](../ADMISSIONS.md) 和 [部署文档](../../deploy/README.md)。
