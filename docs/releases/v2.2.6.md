# v2.2.6

## 界面

- 日志与任务中心：后台任务服务（Worker）未响应时以红色显示并说明“邮件、制证与清理任务暂停”，加载完成前显示占位，不再先显示“暂未响应”。
- 列表筛选栏：桌面端下拉框统一宽度，不再撑满整行；手机上搜索框、下拉框和日期框统一占满整行。
- 面包屑在窄屏上整段换行，长活动名不再被挤压成多列。
- 报名详情：“比赛时间”改为“活动时间”；人数上下限相同时显示“限 N 人”；金额统一称“应收金额”。
- 文件选择按钮增加悬停反馈，未选择文件的提示文字弱化显示。

## 安装与保留数据升级

安装包和五类业务镜像使用固定版本 v2.2.6，支持 linux/amd64 和 linux/arm64。核对同一 Release 的 SHA256SUMS 后解压安装包，运行 `bash install.sh`。

v2.2.5、v2.2.4、v2.2.2、v2.2.1、v2.1.0、v2.0.0 和 v0.10.2 可在原安装目录执行：

```bash
NXOPA_UPDATE_TAG=v2.2.6 bash install.sh update --yes
```

更新先建立加密备份，保留原数据卷、加密密钥、账号、报名、财务、附件及共享比赛凭据，再启动新版服务。本版不含数据库迁移。网关监听非回环地址时，仍需在 `deploy/.env` 中把 `TRUSTED_PROXY_CIDRS` 设为外层代理的具体地址。

降级须恢复升级前的数据库和文件备份。v0.9.x 和已弃用的 v1.0.0 继续使用独立安装目录和数据卷全新部署。
