# V0.6.4

此标签仅保留发布前验证记录，未正式发布。逐行输入问题修复后使用 [V0.6.5](v0.6.5.md) 发布，安装与更新请使用 v0.6.5。

本版支持在后台配置多个信任的请求来源，并补齐先报名、后绑定外部评测平台的同步流程。

- 系统管理员在“管理中心 → 全局设置 → 信任的请求来源”填写多个内外网入口，每行一个或用逗号分隔，保存后立即生效。地址按协议、域名和端口精确匹配，自动规范化及去重；不接受通配符、账号密码、额外路径、查询参数或片段。环境变量配置的来源继续生效，并在后台单独展示。
- 公网 HTTPS 与显式信任的内网 HTTP 入口可同时使用。HTTPS 会话保留 Secure Cookie；已登录写操作继续校验 CSRF。信任列表仅向系统管理员提供，公开站点信息不返回内网入口配置。
- 活动可先开放报名并完成审核、缴费，后期再启用平台联动、绑定 Hydro 或 DOMjudge。新建或保存启用的自动同步绑定时，补同步已有取得资格的报名；后续取得资格的报名继续自动同步。
- 绑定列表新增“同步已有报名”，可批量同步及重试；保留报名详情的逐条同步入口。重试复用已有账号映射和凭据，草稿及未取得资格的报名不派发同步任务。停用的绑定或实例不能发起批量同步。
- 更新安装默认版本、API 文档、操作说明与配置教程，新增来源校验、混合协议登录及后期绑定同步的回归测试。

## 升级

在原安装目录运行：

```bash
NXOPA_UPDATE_TAG=v0.6.4 bash install.sh update --yes
```

本版无需新增数据库迁移，信任来源保存在现有站点设置中。安装器仍会先加密备份，再更新服务并等待健康检查。保留原项目名、数据库密码、`ENCRYPTION_KEY`、附件和升级前备份。Hydro 插件继续使用 0.2.1，适配 Hydro 5.0.7；DOMjudge 继续适配 9.0.1。

## 验证与镜像

新增回归覆盖多个来源增删即时生效、未登录来源校验、权限及 CSRF、地址规范化、内网 HTTP 会话、只读编辑与取消、保存后刷新、后期绑定自动补同步、后续审核通过、手动批量同步及失败重试。新增外接同步用例使用本地 Hydro 协议模拟服务，并核对原报名快照、版本、资格与账号映射。

发布流程执行完整工程和业务回归，再构建 `ghcr.io/albert-li-sz/nxopa-regsys-{api,worker,web,latex,minio}:v0.6.4`，支持 `linux/amd64`、`linux/arm64`。两种原生架构分别执行实际安装、历史版本升级、登录、中文 PDF、HTTPS 代理及加密备份恢复。验收报告、镜像清单、安装包与 SHA256 校验和随 Release 提供；正式发布前核对远端工作流、匿名镜像访问及附件完整性。
