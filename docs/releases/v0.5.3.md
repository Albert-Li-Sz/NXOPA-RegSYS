# V0.5.3

本版修复安全审计发现的财务、账号、会话、Webhook、上传及归档检查问题，并改进费用配置和报名名单导出。

- 费用配置以**元**输入和显示，支持两位小数；接口与数据库继续使用整数分，已有金额不转换、不改账。
- 名单导出将每个成员、队伍、报名及老师字段展开为独立列，包含历史字段、多名老师和标准 CSV 引号／换行处理。每位有效成员一行，团队财务金额仅填在首行。导出需要报名管理权限，财务列另需财务权限；增加数量、大小限制及审计。
- 核账不能改写申报金额，禁止申请人及凭证上传者自审；凭证附件与渠道交易参考号防重复入账。超应收退款由不同管理员批准和完成，历史账目不自动调整。
- 管理员不能直接替换他人登录邮箱；登录前亦检查写请求来源，完善找回、验证、登录及上传限流。演示账号初始化要求显式开发环境开关，正式环境关闭 Swagger。
- Webhook 独立校验 DNS 和目标地址、固定连接 IP、不跟随跳转。内网地址须由系统管理员逐项批准，云元数据与保留地址仍禁止；不影响已有内网评测平台配置。
- 平台同步的网络调用移出长数据库事务；迟到结果不会恢复已删除报名或交付旧凭据，而是保留远端撤权待办。
- 上传在缓冲前检查用途限制，增加并发及存储配额。恢复前校验外层和嵌套归档，拒绝链接、越界路径、重复成员、损坏及过度膨胀数据。
- 增加版本化用途派生密钥、浏览器写请求合并与短期重试、幂等过期清理、脱敏删除审计、生产 CSP／HSTS 及镜像摘要固定。修复生产 CSP 下 PDF 预览的 Blob 读取和表单校验兼容问题。
- 邮件模板变量、条件区块及历史空段落改为顺序解析，避免畸形模板触发重复正则回溯；安全单元测试使用独立配置，不读取本地密钥或连接数据库。

本地已通过 20 组完整回归、77 个浏览器场景、20 项安全接口、24 项单元测试，以及生产 Caddy／PDF、OAuth、恶意归档、类型、构建和格式检查。发布工作流另执行 amd64／arm64 镜像实际安装、升级、代理及备份恢复，并随附件提供结果。详细处理与保留项见[安全复核报告](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.5.3/docs/SECURITY_REMEDIATION_2026-10-15.md)。

## 升级说明

本版增加三个数据库迁移。已有实例使用 `bash install.sh update`，更新前保留加密备份、附件及原 `ENCRYPTION_KEY`。迁移保留历史余额和单据；重复凭证标记为 `VOUCHER_DUPLICATE_HISTORY`，由财务人员人工对账。旧密文和验证码兼容读取。

旧内网 Webhook 不自动获得新审批，需系统管理员明确重新创建并更新接收端签名。额外管理域名通过 `TRUSTED_MANAGEMENT_ORIGINS` 配置；公网地址为 HTTPS 时，浏览器也须使用 HTTPS。回退数据库结构需要恢复升级前备份，不能仅切换应用镜像。

镜像：`ghcr.io/albert-li-sz/nxopa-regsys-{api,worker,web,latex,minio}:v0.5.3`，支持 `linux/amd64`、`linux/arm64`，并更新 `v0.5`、`latest`。安装包固定本次镜像内容摘要。该发布不会自动更新已有服务器；远端 Hydro／DOMjudge 撤权仍需管理员执行并登记。
