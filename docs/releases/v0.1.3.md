# V0.1.3 · 交互式安装、更新与卸载

发布版本：`v0.1.3`。

## 更新内容

- `install/install.sh` 不带参数进入中文交互安装，可选择发布镜像或源码、本机试用、Caddy HTTPS 或已有反向代理；自动生成私密配置、等待健康检查并创建首次管理员。
- 新增 `install/update.sh`，交互选择固定镜像版本，先按原配置加密备份，再更新服务。备份失败中止升级，拉取或启动失败保留原配置。
- 新增 `install/uninstall.sh`，默认卸载容器并保留数据。永久删除数据卷须准确输入 `DELETE 项目名`；配置和加密备份保留，备份失败中止卸载。
- 共用 `lib.sh` 并保留原有维护子命令。安装包包含全部入口与辅助文件，支持从任意工作目录及指定环境文件运行，不执行 `.env` 中的 Shell 内容。
- 网页与 PDF 配置教程同步说明三个入口。PostgreSQL、Redis、Caddy 继续使用各自官方镜像，业务服务保持独立容器。

## 安装与更新

新安装下载 `nxopa-regsys-v0.1.3-install.tar.gz` 和 `SHA256SUMS`，核验后解压，进入 `install` 目录执行：

```bash
bash install.sh
```

已有部署先取得新版安装材料，保留原 `.env`、项目名、数据库密码和加密密钥，然后执行 `bash update.sh`，目标版本填写 `v0.1.3`。源码部署先取得新版完整源码，再运行更新入口。

只有安装入口发生变化，不需要重新创建管理员。从 `v0.1.1` 或更早版本跨版本升级时，旧的未使用邮箱验证与密码重置链接失效；原会话、报名、财务和附件保留。

API、Worker、前端和 LaTeX 镜像标签均为 `v0.1.3`，支持 `linux/amd64` 与 `linux/arm64`。附件包括安装包、镜像摘要、两个架构的既有安装与交互安装验收 JSON、配置教程及 Hydro 0.2.0 插件。使用 `SHA256SUMS` 校验附件。

## 验证

16 项脚本边界检查覆盖地址、版本、端口和隐藏密码校验、取消与输入结束、旧配置及密钥保留、备份失败、拉取或启动失败、卸载确认和默认保留数据。

发布流水线分别在原生 amd64 / arm64 上完成空库安装、管理员登录、中文 PDF、重启、加密备份恢复及 `v0.1.1` 升级回归；另通过三个交互入口完成 `v0.1.2` 安装、升级到新版、保留数据卸载与重装、永久卸载。发布前核验四个公开镜像的内容摘要、双架构、版本及源码提交。

数据库迁移已经执行后若需降回旧版，应先恢复升级前备份。取消报名阻止本地比赛账号交付，已有远端评测账号仍按评测管理员流程处理。
