# v0.7.2

将 Hydro / DOMjudge 直接同步替换为平台导入文件导出。此版本包含破坏性更新及数据库迁移。

- 移除 OJ 实例与服务凭据配置、比赛绑定、远端学校映射、自动／手动同步、账号交付、同步回调，以及本站 Hydro 桥接插件和适配器包。
- 新增“平台导出中心”及活动内的“平台文件导出”，仅有对应活动权限的管理员可下载合格报名。支持排除非正式报名或全部按非正式导入。
- Hydro 使用官方最新版 Onsite Toolkit 的 `onsiteImport` JSON，包含学校、成员、老师、座位与排名性质。登录名采用可读姓名片段和唯一后缀，真实队名／姓名同时写入 `displayName`。
- DOMjudge 9.x 导出 `groups.json`、`organizations.json`、`teams.json`、`accounts.json`，固定队伍角色并保持学校、分组、队伍和用户的外部 ID 关联。正式与非正式分组使用不同排名顺序。
- 修复导出 URL 末尾斜杠或大小写变体在重复使用幂等键时挂起下载的问题，所有导出路径均直接返回完整 ZIP。
- 同一报名与平台的账号密码稳定，加密保存；导出包附明文密码表及教程。导出不进入幂等响应缓存，下载响应禁止缓存，密码不写审计。
- 座位加活动前缀，防止跨比赛冲突；重复座位、多个成员座位、缺少完整代表单位或冲突学校资料均拒绝导出。JSON 直接保留中文和 `NULL`，CSV 防止公式执行。
- 升级停用旧实例与绑定、移除旧服务凭据、取消旧同步任务，并为旧远端账号补充人工撤权待办。新的文件导出不复用旧同步账号。
- 导出请求格式放入纯契约模块，OpenAPI 与规范测试无需加载数据库配置，可在无 `.env` 的干净环境执行。
- 修复通过手工 URL 显示无权限导出控件的问题，以及并行启动／构建前端时 PDF.js 资源复制相互覆盖导致启动失败的问题。
- 重写在线教程与 PDF 的 Hydro、DOMjudge 及导出章节，说明实际导入顺序、最新版命令参数、重导密码行为、外榜昵称、IP 登录与赛后清理注意事项。

真实平台验收使用 Hydro 5.0.7 + Onsite Toolkit 0.1.1、DOMjudge 9.0.1，验证文件导入、关联读回、重复导入及比赛账号实际认证。发布流程将两种真实平台导入纳入验证，验收记录与双架构安装、完整业务回归报告随 Release 提供。

升级前备份数据库、文件和加密密钥。已有比赛正在使用旧同步账号时，不要在赛中切换。文件导出不会自动导入、删除或撤销远端账号；资格撤销、取消／删除报名后由评测管理员手动处理。DOMjudge 目标比赛需允许相应分组参赛。

在原安装目录更新：

```bash
NXOPA_UPDATE_TAG=v0.7.2 bash install.sh update --yes
```

操作教程见 [平台导入说明](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.7.2/docs/INTEGRATIONS.md)及[在线配置教程](https://albert-li-sz.github.io/NXOPA-RegSYS/)。
