# V0.3.6

本版修复细分管理授权、附件并发、邀请返回流程和大文件反向代理问题，并将独立数据库的完整业务与浏览器回归加入发布校验。

- 工单列表、正文、附件和邮件投递状态统一检查工单管理权限；只有“查看竞赛”授权不能读取其他用户工单，参与人仍可查看所属队伍的工单。
- 修复并发删除附件与提交缴费凭证时，财务记录可能引用已删除文件的问题。绑定和删除在同一文件锁下完成，已经使用的财务凭证保留。
- 工单拒绝已删除、公开或已经绑定其他工单的附件，避免无效链接和旧工单附件被转移。
- 教师实名资料验证真实日历日期；学生视图拒绝无效入学年份，并兼容历史字符串年份，审核后统一保存数字年份。
- 邀请注册和登录保留邀请确认页面的返回路径，资料完善检查继续用于报名。过期邮箱验证链接显示持续可见的错误说明。
- 修复高级管理员被显示为“取消系统管理员”的错误操作，系统角色与高级角色分别识别。
- Nginx 示例允许 50 MB 文件及表单头完整转发到 Caddy，修复原 30 MB 上限导致的大文件 413。
- 完整回归使用独立 PostgreSQL、Redis、SMTP 与隔离 LaTeX，涵盖报名、财务、认证、授权、邮件、准考证、工单、MCP、浏览器和负载；新增越权与确定性并发回归。发布附件增加 `full-regression.json`。

保留 V0.3.5 的 MinIO / 第三方 S3、头像与附件、公示、个人中心、期限授权、邮件模板和 GitHub 登录功能。本版没有新增数据库迁移。

已有实例先备份，再运行 `bash install.sh update`；使用 Nginx 的实例同时检查上传上限，参考 [反向代理示例](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.3.6/deploy/nginx.conf.example)。镜像发布后会继续执行 amd64 / arm64 原生安装、旧版升级、双层代理和加密备份恢复验收，结果随 Release 附件提供。
