# v2.1.0

## 更新

- Hydro 新增默认导出和自选字段导出。固定保留 id、name、rank，其余六项可选；取消密码后 JSON、凭据 CSV 及整个 ZIP 均不含比赛密码，保存的密码不变。
- 管理员仅可修正审核通过、待补正报名；完整校验后“保存并送复核”，由管理员直接审核，无需选手重交。截止后允许代改，归档后只读。
- 修正同步更新报名快照、费用差额和审计历史，暂停资格并使旧准考证失效；保留报名 UUID、首次提交时间、到账记录及共享比赛密码。自动审核活动的代改也须人工复核。
- 补充管理员修订记录展示、真实 PDF 中文文字校验、Hydro 自选文件重导、状态与权限边界、并发保存／审核回归。

## 安装与保留数据升级

镜像与安装包使用固定版本 v2.1.0，支持 linux/amd64、linux/arm64。新安装核对本 Release 的 SHA256SUMS 后解压运行 bash install.sh。

v2.0.0 与 v0.10.2 在原安装目录执行：

```bash
NXOPA_UPDATE_TAG=v2.1.0 bash install.sh update --yes
```

升级先建立加密备份，保留原数据卷、加密密钥、账号、报名、财务、附件和比赛凭据。资格校正分批、幂等执行：历史待审核却被标记合格的报名暂停资格、使旧文档失效，审核状态与历史快照不改写。审核通过的正常报名不受此校正影响。降级须恢复升级前备份。

v0.9.x 与已弃用 v1.0.0 仍须使用独立安装目录和数据卷全新部署。

## 导入注意

省略 password 不重置已有 Hydro 账号密码；新账号由 Hydro 随机生成密码，可能与本站准考证不同。省略 members 可能清空远端成员。默认完整导出维持共享凭据规则。管理员修正后重新生成准考证并核对目标平台重导结果。

## 验证

发布门槛包含完整回归、Browser 交互、实际 PDF、真实 Hydro／DOMjudge 导入与登录，以及两个架构的全新安装、重启、加密备份恢复、v2.0.0 与 v0.10.2 保留数据升级。验收报告随 Release 提供。
