# V0.5.0

本版重构活动及竞赛报名流程，新增独立财务、多考场排考和通用活动预设，统一查看／编辑模式与可配置分页，并修复管理员与报名方操作混用。

- 取消或由报名管理员删除报名后，永久移除报名资料、成员、审核快照、邀请及准考证，释放报名限制和座位。财务账户、收款凭证、账簿、退款与发票独立保留，删除本身不自动退款。
- 审核使用独立信息弹窗，支持通过、退回补正、拒绝及连续审核。已有结论使用“修改审核”，更改结论、退回或拒绝须填写原因；尚未重新提交的修改资料不能审核。
- 管理员查看他人报名时使用修改及保存，不因管理权限获得代提交、财务申请等报名方操作。保存的个人资料、报名、活动与系统配置默认只读，点击编辑后修改；取消恢复原值，失败保留草稿。
- 支持通用活动／竞赛预设，以及个人／团队报名。通用活动默认免费、人工审核、无需老师，并关闭准考证、考场和评测平台；启用或关闭功能在服务端同步校验。
- 新增多考场及座位管理，支持手动分配、自动排考、CSV 导入与提交前预览。支持个人一人一座、团队一队一座或按成员排考；容量不足、座位冲突及过期预览整批拒绝，调整考场或座位使受影响准考证失效。
- 活动管理入口改为“活动及竞赛管理中心”，“参赛资格已确认”改为“参加资格已确认”。活动管理列表分别显示正式、非正式参加人数，团队按有效成员人数计，不含草稿、撤回或已删除报名。
- 表格、列表和长表单默认每页 20 项，可选 20／50／100，分别记住选择。翻页保留草稿及勾选，删除末页记录自动回退；附件、邮件、会话及完整实名审核历史可查看较早记录。
- 修复活动标题搜索、草稿与待审统计、截止后编辑入口、必填附件删除后资格失效、财务权限及已冲正收款重复操作等流程问题。已同步外接平台的报名删除后生成明确的人工撤权待办，停止本地同步及凭据发放。

已有实例使用 `bash install.sh update`，更新器先生成加密备份。请保留数据库、附件和原加密密钥；本版升级会迁移财务外键并永久清理历史 `CANCELLED`、`CANCEL_REQUESTED` 报名，不补发历史取消通知。升级后核对财务余额、单据和附件。永久清理后的回退必须恢复升级前数据库与文件备份，仅回退镜像不能恢复报名资料。

发布镜像为 `ghcr.io/albert-li-sz/nxopa-regsys-{api,worker,web,latex,minio}:v0.5.0`，支持 `linux/amd64` 与 `linux/arm64`。发布流程执行工程、业务与浏览器回归、两种架构的实际安装及升级、交互安装、代理和加密备份恢复检查，报告与镜像摘要随 Release 附件提供。

操作说明见 [平台指南](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.5.0/docs/PLATFORM_GUIDE.md)，迁移和回退见 [部署说明](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.5.0/docs/DEPLOYMENT.md)。
