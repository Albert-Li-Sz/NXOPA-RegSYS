# V0.6.6

本版支持在竞赛配置中维护考点，选手报名时选择参赛地点，并将考点贯通到排座、准考证和报名导出。

- 管理员在竞赛配置的“考点选择”中新增考点、填写名称和地址，并设置开放状态。每个竞赛最多 100 个考点，名称不可重复；配置保存后供选手选择。
- 配置考点后，提交报名必须选择一个开放考点，团队成员共用同一考点。草稿可暂不选择；未配置考点的历史竞赛保持原报名流程。
- 停用考点后停止新选择，已有已提交报名保留原选择。被报名或考场使用的考点不能直接删除，须先调整关联数据或改为停用。选手改选考点后会清除原座位、失效旧准考证，并要求重新提交。
- 考场关联所属考点，自动排座、手动排座及 CSV 导入均校验考点，避免跨考点分配。已有座位的考场更换所属考点前须清空座位。
- 报名管理新增考点列和筛选，CSV 名单导出包含考点及地址。报名详情展示考点信息；准考证地点合并考点名称、地址和考场地址。考点名称或地址修改后，旧准考证失效并须重新生成。
- 更新 API、配置教程、安装默认版本和发布回归，覆盖个人与团队报名、停用兼容、历史数据升级、考点改选、排座及活动删除。

## 升级

在原安装目录运行：

```bash
NXOPA_UPDATE_TAG=v0.6.6 bash install.sh update --yes
```

本版包含数据库迁移 `202610200001_exam_sites`，新增考点表，以及报名、考场的可空考点关联。安装器会先加密备份，再执行迁移并等待健康检查。未配置考点的历史活动无需补数据；已有报名的活动后期新增考点时，须补充报名考点后再排考或制证。保留原项目名、数据库密码、`ENCRYPTION_KEY`、附件及升级前备份。Hydro 插件继续使用 0.2.1，适配 Hydro 5.0.7；DOMjudge 继续适配 9.0.1。
