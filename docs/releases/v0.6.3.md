# V0.6.3

本版修复审计报告中经代码核对和功能验证确认的问题，覆盖任务执行、附件与备份、报名与财务分离、外部平台同步和表单交互。已处理的 `audit-reports` 目录已删除，回归用例随源码保留。

- 后台任务增加租约与执行令牌，回收超时任务时阻止旧执行者重复提交；通知失败采用有上限的退避重试。
- 修正上传超时与并发校验、附件清理和配额回收、存储迁移条件更新及备份恢复清单验证。LaTeX 编译任务在临时目录被并发清理时可以安全结束。
- 取消报名后永久删除报名记录，独立保留账目与相关财务依据；补齐批量制证重复检查、延时发放及并发请求幂等处理。
- 外部同步在事务内校验报名状态、权限与映射；固定已校验的连接地址，拒绝不受控跳转，避免探测与请求之间地址变化。完善远端成功但响应丢失后的恢复与去重。
- Hydro 插件更新至 **0.2.1**，严格校验布尔字段；继续适配 Hydro 5.0.7。DOMjudge 继续使用 9.0.1，未放宽兼容性检查。
- 修正保存后的只读展示、草稿恢复、操作中状态、权限和搜索范围；补齐邮件、MCP 响应和 OpenAPI 必填路径参数校验。
- 安装材料统一归属与文件权限，完善备份恢复临时资源清理。同步安装入口、配置教程和插件下载版本。

## 升级

本版新增数据库迁移 `202610170000_audit_lifecycle`，添加后台任务租约、通知重试和附件清理状态。安装器更新时先自动加密备份，再执行迁移并等待健康检查。在原安装目录运行：

```bash
NXOPA_UPDATE_TAG=v0.6.3 bash install.sh update --yes
```

保留原项目名、数据库密码、`ENCRYPTION_KEY`、附件和升级前备份。需要回退时按[部署文档](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.6.3/docs/DEPLOYMENT.md#加密备份与恢复)恢复匹配版本的备份。Hydro 插件需在 Hydro 所在环境单独安装 0.2.1 包。

## 验证与镜像

发布前本地完整回归通过 21 组套件，包括 80 项浏览器测试；另通过 47 项单元测试、审计专项、安装引导和备份恢复检查。使用 Docker 部署真实 Hydro 5.0.7 和 DOMjudge 9.0.1，各通过 6 组集成套件，覆盖账号与比赛导入、昵称和排名性质、权限、状态变更以及响应丢失后的自动恢复。DOMjudge 使用官方打包源码构建 9.0.1；测试创建的容器、镜像、卷、网络和临时文件均已清理。

镜像为 `ghcr.io/albert-li-sz/nxopa-regsys-{api,worker,web,latex,minio}:v0.6.3`，支持 `linux/amd64`、`linux/arm64`。安装器使用完整版本标签；PostgreSQL、Redis、Caddy 保持独立的固定版本官方容器。

发布工作流重新执行工程与完整业务回归，使用当前源码构建 LaTeX 测试镜像，并对两种原生架构执行镜像构建、安装升级、HTTPS 代理和备份恢复验收。结果与校验和随 Release 附件提供，验收通过并核对公开镜像与附件后发布正式 Release。
