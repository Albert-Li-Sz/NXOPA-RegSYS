# v2.2.5

## 安全与可用性

- 网关监听回环地址（默认 `127.0.0.1`）且未设置 `TRUSTED_PROXY_CIDRS` 时，安装器自动信任本机反向代理经 Docker 转发的来源，后端可获得真实客户端 IP。此前所有请求被视为同一来源，按 IP 的登录、注册、找回密码限流会被全站共享。监听 `0.0.0.0` 或其他地址时仍不自动信任，启动时提示填写外层代理的具体地址。
- 上传并发改为按内存预算控制（默认 512 MB），每人同时最多 2 个；此前全站同时只能上传 2 个文件。
- 登录失败锁定改为按“账号 + 来源”计数，他人无法通过故意输错密码锁定指定账号；账号整体失败上限仍阻止分布式猜测密码。
- 同一浏览器重新登录时撤销此前的会话。
- 报名参与者不能再查看同一报名下的邮件等内部任务；预览下载先校验权限再提示过期。
- 匿名导出公示名单增加按来源和按活动的限流。
- 删除附件时只在可能引用它的报名中查找，不再扫描全部报名资料。

## 界面

- 管理员导航中，个人入口在前，管理中心以“管理”分隔；未登录时只显示活动入口。
- 窄屏下导航右侧渐隐提示可滑动，触屏设备的表格横向滚动条保持可见；管理列表的活动名称可直接进入配置。
- 活动配置页的“删除活动”改为描边按钮，开启队伍公示时提示会公开的个人信息。
- 首次加载显示占位，活动列表与登录页统一使用“活动”称呼；登录页的“返回首页”替代原先回到登录页的链接。

## 安装与保留数据升级

安装包和五类业务镜像使用固定版本 v2.2.5，支持 linux/amd64 和 linux/arm64。核对同一 Release 的 SHA256SUMS 后解压安装包，运行 `bash install.sh`。

v2.2.4、v2.2.2、v2.2.1、v2.1.0、v2.0.0 和 v0.10.2 可在原安装目录执行：

```bash
NXOPA_UPDATE_TAG=v2.2.5 bash install.sh update --yes
```

更新先建立加密备份，保留原数据卷、加密密钥、账号、报名、财务、附件及共享比赛凭据，再启动新版服务。本版不含数据库迁移。使用外层反向代理且网关监听非回环地址时，请在 `deploy/.env` 中设置 `TRUSTED_PROXY_CIDRS` 为代理的具体地址。

降级须恢复升级前的数据库和文件备份。v0.9.x 和已弃用的 v1.0.0 继续使用独立安装目录和数据卷全新部署。
