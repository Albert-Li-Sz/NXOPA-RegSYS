# v0.6.7

对账号授权、报名、财务、附件、准考证、平台同步、前端交互及发布流程进行全项目审计，修复 8 项确认的权限与资源边界问题，并补齐相关流程回归。

- 老师被移除、管理授权被撤销或主动卸任后，旧邀请不会恢复已失去的权限。
- 普通查看及报名审核权限只保留财务摘要；详细凭证、发票、银行资料与财务附件需要财务权限或报名参与关系。
- 撤回平台使用授权会停用已有绑定，阻止账号交付并登记远端人工撤权待办。重新验证同步成功后关闭相同目标和账号的旧待办，保留其他目标的待办。
- 学校映射继续共享；涉及其他竞赛时由系统管理员确认。
- UUID 大小写使用同一事务锁，防止并发申请超额开票或退款；收款冲正及必需附件失效判断也统一处理大小写。
- 限制模板展开总工作量和输出大小；外部平台响应限制为 10 MiB。未实际开票或退款的处理不能绑定未经验证的附件。
- 修复个人照片附件在审核及准考证生成时的授权衔接，以及编译任务重启后残留文件导致的失败。
- 上传期间保护保存、取消和退出流程；过期会话支持原账号恢复登录并保留草稿。独立保存全局模板不会覆盖站点配置草稿；HTTP 环境可新增考点；财务刷新被拒绝后清除旧记录和操作控件。
- 发布必须通过同一提交、干净源码的 23 组完整回归，浏览器筛选、跳过、不稳定结果不能作为发布证据。修正部署、教程和测试脚本中的过期流程。

本版不增加数据库迁移。升级前按正常流程备份，保持原项目、数据卷和加密密钥。远端自动撤权仍需平台适配器支持，目前通过明确的人工待办处理。

在原安装目录更新：

```bash
NXOPA_UPDATE_TAG=v0.6.7 bash install.sh update --yes
```

审计范围与复现验证见 [审计与修复记录](https://github.com/Albert-Li-Sz/NXOPA-RegSYS/blob/v0.6.7/docs/AUDIT_2026-10-21.md)。安装、完整回归及两个架构的镜像验证结果随 Release 附件提供。
