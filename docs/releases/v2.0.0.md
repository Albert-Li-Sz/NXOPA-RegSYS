# v2.0.0

本版本完善报名资料与院校目录，修复邮箱变更后的报名同步，并调整活动信息对齐。Hydro、DOMjudge、准考证继续共享本人／队长学号和稳定的系统随机比赛密码。

- 入学年份改为年份选择，支持 1950 年至下一年。升级时规范可识别的旧年份，清空不合理的当前值，保留其他资料及历史审核、报名修订记录。
- 内置教育部截至 2026 年 6 月 17 日的 1,412 所本科院校，支持名称、地区搜索。系统管理员可添加其他院校或单位、维护简称与搜索别名、停用条目；历史单位名称仍可保留。
- 默认添加敏感邮箱字段。绑定成员和教练跟随账号邮箱，手工成员可填写邮箱；验证并更换登录邮箱后同步已有报名和快照，使旧准考证失效。导出避免重复邮箱列。
- 学生统一使用“学号”，教职工使用“职工号”。活动信息值靠近标签并对齐，费用标签按四字宽度排列，支持手机端换行。
- 增加旧数据迁移、单位管理、邮箱同步和桌面／手机端交互测试；更新在线教程及 PDF。
- 修复 macOS tar 将文件来源扩展属性写入备份，导致恢复前校验拒绝备份的问题；继续严格检查归档路径和元数据。

## 安装与升级

下载本 Release 的固定版本安装包，核对 `SHA256SUMS` 后解压运行 `bash install.sh`。五类业务镜像均使用 `v2.0.0` 固定标签，支持 linux/amd64 与 linux/arm64。

从 v0.10.2 升级，在原安装根目录执行：

```bash
NXOPA_UPDATE_TAG=v2.0.0 bash install.sh update --yes
```

升级先建立加密备份，保留原数据卷、加密密钥、报名 UUID 和共享比赛密码。资料规范化可能使旧准考证失效，请重新生成并检查后发布。v0.9.x 与已弃用的 v1.0.0 使用独立安装目录和数据卷全新部署。
