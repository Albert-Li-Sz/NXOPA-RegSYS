# 2026-10-12 增强功能验收

本轮在既有 MVP 上完成公网地址、分页、平台基础资料与非正式报名、Hydro／DOMjudge 联动、中国发票申请、Markdown、后台界面及教程下载增强。保持独立首页、邮箱密码登录和链接确认授权，不恢复 OAuth／OIDC。

以下结果来自本轮实际执行：原生开发服务、真实 PostgreSQL／Redis、独立 Hydro 5.0.7／DOMjudge 9.0.1，以及生产 Docker Compose。平台验收创建真实学校、队伍及账号，并使用生成的账号登录；失败恢复测试先把请求交给真实平台，随后丢弃一次成功响应，没有以模拟平台代替远端注册。

| ------------- | ---------------------- |
| 总耗时        | 1,288 毫秒             |

## 已知平台约束

DOMjudge 9.0.1 的账号更新接口有限。远端账号名称或邮箱与期望值不同会显示需人工处理，管理员在远端修改后再同步；队伍编号／座位在远端全局唯一，冲突明确显示占用队伍。成员姓名与英文队名按该版本的公开说明存储机制保存。

当前适配器未声明自动停用远端账号能力。本站资格失效会停止交付旧比赛凭据、失效准考证及同步结果，管理员仍须在 OJ 内处置已存在的远端账号。邮件检查使用本地 Mailpit，不声明已完成外部邮箱服务的公网投递。
