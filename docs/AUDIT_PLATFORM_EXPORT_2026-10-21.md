# 平台导出改版检查与修复

本轮覆盖平台导出、旧同步停用与迁移、报名与资格、权限、财务、附件、准考证、邮件、浏览器交互、教程和发布流程。当前行为与导入步骤以 [INTEGRATIONS.md](INTEGRATIONS.md) 为准。

## 确认并处理的问题

| 问题                                                        | 修复及验证                                                                                                                                                           |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 手工 URL 可显示缺少导出授权的活动控件                       | 活动页同时检查 INTEGRATIONS 权限与功能开关；浏览器测试覆盖授权撤回后刷新及直接 URL。服务端独立检查当前权限。                                                         |
| 同名用户名、跨比赛座位冲突，部分外榜忽略昵称                | Hydro 登录名使用可读姓名片段与唯一后缀；displayName 保留完整名称；座位带活动前缀，重复与不支持的逗号／换行拒绝导出。真实 Hydro 验证姓名、成员、性质、重导和登录。    |
| 重复或并发导出可能换号、换密码                              | 平台与报名联合唯一约束、事务锁、加密凭据与批量持久化；并发下载核对相同文件数据和数据库账号数。                                                                       |
| 旧同步任务及已创建远端账号在升级后失去处理入口              | 迁移取消 SYNC、移除旧服务凭据，并为旧远端账号保留人工撤权待办；Worker 不执行旧同步，旧接口移除，重试被拒绝。                                                         |

| 账号密码导出被普通报名、缓存或 CSV 公式泄露                 | 活动级导出授权、CSRF 检查、no-store 响应、排除幂等响应缓存、CSV 公式转义，审计仅记录范围与数量。                                                                     |

## 验证方式

- `pnpm typecheck`、`pnpm format:check`、`pnpm test`、`pnpm build`、`pnpm audit:runtime`。
- `pnpm test:platform-exports`：权限、CSRF、无资格过滤、NULL、公式转义、加密、并发稳定性、重复座位、分组与关联、停用模块和旧接口移除。
- `pnpm test:oj`：部署 Hydro 5.0.7 / Onsite Toolkit 0.1.1、DOMjudge 9.0.1，使用本站下载的文件调用官方导入流程，读回数据并实际认证。
- `pnpm test:full`：完整业务和全部浏览器检查，发布要求同一提交且源码干净，无跳过、不稳定或仅运行筛选用例。
- 平台功能、安装引导、固定镜像标签、静态文件、备份恢复，以及发布镜像 amd64 / arm64 安装、升级和 HTTPS 代理验收。
- 教程从 LaTeX 构建网页，检查命令、链接、截图、下载摘要，并渲染修改的 PDF 页面检查排版。

发布工作流额外启用 `FULL_REGRESSION_OJ=1`，依次运行两种真实平台导入并停止临时服务，以控制资源占用。平台报告绑定提交与干净源码状态，打包必须验证报告后再交付。

## 交付边界

导出只生成文件，不表示目标平台导入完成。资格撤销或报名删除后的远端权限由评测管理员处理。正在比赛的旧账号不自动迁移到新账号；破坏性升级前备份，回退应用前同时恢复数据库与文件。未对生产报名数据执行导入或修改。
